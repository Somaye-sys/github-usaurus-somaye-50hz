How to deploy a Docusaurus site to GitHub Pages

Overview​

In this tutorial, you'll see how to deploy a Docusaurus website to GitHub Pagesto host your documentation online. This makes it easy to share your documentation, keep it up to date, and manage changes using Git.

It assumes you have knowledge of:

  • Using GitHub.
  • Running simple commands in a terminal.
  • Editing files in a code editor.

By the end of this tutorial, you'll be able to:

  • Run a Docusaurus site on your computer.
  • Prepare the site for GitHub Pages.
  • Publish the site and open it in your browser.

Before you start​

Before you start the tutorial, make sure you have the following installed.
Select the links below to download and install each tool if needed.

  • Node.js (version 14 or higher)
  • Yarn
  • Git
  • GitHub account
note

This tutorial uses an example Docusaurus repository: https://github.com/your-github-username/github-usaurus.git.

Deploy a Docusaurus site to GitHub Pages​

To get started, clone the project repository to your local machine.

Clone the repository​

  1. Open a terminal.
  2. Run:
git clone https://github.com/your-github-username/github-usaurus.git
  1. Move into the project directory:
cd github-usaurus

Install dependencies​

Install the project dependencies using Yarn:

yarn

Run the site locally​

Start the local development server by running:

yarn start
tip

If the site starts successfully, you'll see the Docusaurus website open in your browser at http://localhost:3000.

Create a GitHub Pages branch​

GitHub Pages uses a branch named gh-pages to publish the website.

  1. Run the following commands in the project directory:
git checkout -b gh-pages
git add .
git commit -m "chore: create gh-pages branch"
git push -u origin gh-pages

Configure Docusaurus for GitHub Pages​

Open the docusaurus.config.ts file in a code editor.

Update the following values to match your GitHub username and repository name:

url: 'https://your-github-username.github.io',
baseUrl: '/your-repository-name/',

organizationName: 'your-github-username',
projectName: 'your-repository-name',
note

Make sure the baseUrl starts and ends with a forward slash (/). Save the file after making the changes.

Generate a GitHub personal access token​

To deploy the site, you need a GitHub personal access token.

  1. In GitHub, open your Profile menu → Settings → Developer settings → Personal access tokens → Tokens (classic).
  2. Select Generate new token → Generate new token (classic).
  3. add a note such as Docusaurus deployment, and select the scopes read:packages and write:packages.

  1. Select Generate token and copy the token.

note

Save the token. You will need it when deploying the site.

  1. Set the required environment variables in your terminal:
export NPM_GITHUB_AUTH_TOKEN="YOUR_PERSONAL_ACCESS_TOKEN"
export GIT_USER="your-github-username"

Deploy the site​

Deploy the website to GitHub Pages by running the following command:

yarn deploy
tip

This command builds the site and publishes it to the gh-pages branch.
If the deployment is successful, the site is published to GitHub Pages.

View the deployed site​

Open a browser and go to the following URL: https://your-github-username.github.io/your-repository-name/

Summary​

In this tutorial, you've now seen how to:

  • Run a Docusaurus site locally
  • Configure a project for GitHub Pages
  • Deploy a documentation site using a docs-as-code workflow
